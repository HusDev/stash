    Pinned to a key.

    Your secrets stay secret.

    Install in a minute.

    1. Download Stash.dmg and drag Stash into Applications.
    2. Open it the first time with right-click → Open. Stash isn't signed with an Apple developer certificate yet, so macOS asks once.
    3. Allow Accessibility in System Settings → Privacy & Security. It lets Stash find your text cursor and paste for you. Without it, Stash copies and you press ⌘V.

    Or build it yourself

    You need Rust and Node.js. Stash is about 1,600 lines of Rust and plain JavaScript on Tauri 2.

    $ git clone https://github.com/HusDev/stash.git
$ cd stash
$ npm install
$ npm run build

    The app lands in src-tauri/target/release/bundle/macos/Stash.app. Run npm run dev while hacking on it.
